Latar Belakang

Website ini dibuat sebagai tugas kampus untuk mata kuliah pemrograman web. Tujuannya adalah membangun sebuah website statis bertema bebas, dengan syarat utama: tidak boleh memakai framework CSS maupun framework JavaScript apa pun. Seluruh halaman harus dibangun dari nol memakai HTML dan CSS murni.

Tema Tarot de Marseille dipilih karena kekayaan visualnya. Kartu-kartu klasik dari Prancis ini memiliki gaya gambar yang khas — sederhana namun penuh simbol, dengan warna merah, biru, kuning, dan hijau yang tegas. Gaya inilah yang coba dihadirkan kembali melalui palet warna parchment, merah bata, biru pucat, dan sentuhan emas pada setiap halaman.

Tantangan terbesar justru muncul saat membuat halaman ramalan. Karena tidak boleh memakai JavaScript, interaksi “ambil satu kartu” dibangun memakai teknik checkbox/radio hack: pilihan pengunjung disimpan pada tombol radio tersembunyi, lalu CSS memutar kartu tiga dimensi sesuai pilihan tersebut. Hasilnya, kartu bisa berputar menampilkan wajahnya tanpa satu baris skrip pun.

Yang Dipelajari dari Proyek Ini

  • Menulis struktur HTML5 yang semantik dengan elemen seperti header, nav, main, section, dan footer.
  • Menyusun sistem desain memakai CSS custom properties (variabel) agar warna dan tipografi konsisten.
  • Mengatur tata letak responsif dengan CSS Grid dan Flexbox.
  • Membuat transisi dan animasi halus untuk tombol, kartu, dan elemen dekoratif.
  • Membangun interaktivitas murni CSS, termasuk kartu berputar dan penyaring galeri.
  • Menerapkan dasar aksesibilitas seperti label tombol, teks alternatif gambar, dan tautan lompat ke konten.

Catatan Teknis

  • Tanpa framework: tidak ada Bootstrap, Tailwind, React, maupun Vue.
  • Tanpa JavaScript: seluruh interaksi dibangun memakai teknik CSS murni.
  • Aset gambar kartu menggunakan berkas lokal dari folder card/.
  • Punggung kartu pada halaman ramalan digambar murni memakai CSS, tanpa berkas gambar.
  • Font dimuat dari Google Fonts dengan cadangan Georgia dan Times New Roman.

Gambar kartu yang dipakai di website ini merupakan restorasi Tarot de Marseille oleh Yoav Ben-Dov (2010), berdasarkan dek klasik yang dicetak di Marseille oleh Nicolas Conver pada tahun 1760, dengan lisensi CC BY-NC-SA 2.0. Gambar tersebut hanya digunakan untuk keperluan akademik, bukan untuk tujuan komersial.
